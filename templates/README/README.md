# README templates

Canonical skeletons for `9aia/*` repo `README.md` files, plus the
rules they share. Each repo is its own git repo; templates are
rendered per repo and committed there — this directory is the
single source of truth for *shape*. The floor stubs (AGENTS.md,
SECURITY.md, CONTRIBUTING.md, cypera.toml) are `lasius conform`'s
job, not these templates.

## Templates

9aia repos aren't prefix-coded families — pick by stack:

| Template | Repos |
|---|---|
| `engine.md` | Rust workspace repos — `crates/` + ports-and-adapters engines (tamias, myco, kuda, mimus, sturn, cuora, cypera, scarab, lasius, tarsi, sepia, cicada, hypha, bupha, tardigrada, pavo, …) |
| `web.md` | JS/TS apps — Nuxt/VitePress/Slidev repos (pachira, camelus, castor, delphis, mycena, themes, 9aia.github.io) |
| `bare.md` | everything else — ledger mounts, archives, oddballs |

## Placeholders

`{{REPO_NAME}}` dir name · `{{TAGLINE}}` one line (matches
`projects.yaml` `tagline` where cataloged) · `{{DESCRIPTION}}`
one sentence · `{{WHY}}` the problem it solves · `{{QUICKSTART}}`
real commands · `{{COMMANDS_NOTE}}` how the command ships (tamias
pack vs cargo bin vs script) · `{{DOCS_URL}}` docs site URL (omit
section when none) · `{{OPTIONAL_EXTRA_SECTIONS}}` for `bare`.

## Rules

- **License is always MIT** — every repo carries a `LICENSE` with
  the MIT text (`Copyright (c) 2026 9aia`).
- **No provenance** — no ADR citations, no "part of the X split",
  no history notes.
- **Docs = one link** — `## Documentation` is a bare URL to the
  repo's page on the docs hub; the Diátaxis structure lives inside
  the docs site, never spelled out here. Omit when no site exists.
- **Status honesty** — "scaffold"/"wip"/"pending" only if true
  today; verify against code before writing.
- Normalize structure, keep existing prose — do not rewrite good
  bespoke sections; move/reorder to match the skeleton.
- Omit optional sections rather than leaving placeholders.
- **Command shipping** — engine repos mostly ship as tamias packs
  (`libraries/<name>/tamias.yaml`, `bins[]` shim); say how to
  install in Quickstart, link AGENTS.md for depth.
- **specs/** — every repo carries `specs/<name>.toml` (generated by
  `scripts/gen-repo-specs.py`); README changes don't touch it, but
  new top-level files may need a spec `cover` entry — run
  `scripts/standard.sh <name>` to check.
